# Ahmad Saleem — Portfolio

Lavender and purple responsive personal portfolio.

## Files
- `index.html` — website content
- `style.css` — colors, layout and responsive styling
- `script.js` — mobile navigation and current year
- `README.md` — instructions

## Preview
Extract the ZIP and open `index.html` in a browser. Keep all files together in the same folder.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `ahmad-saleem-portfolio`.
2. Upload all four files into the repository's root folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub Pages will provide your published website URL.
